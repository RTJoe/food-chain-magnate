# Open Rules Questions

Genuine ambiguities left after checking both Deluxe rulebooks (DLX = base, KX-DLX = Ketchup; printed page numbers). Each item gives the recommended implementation so code is not blocked. Answer source wanted: designer ruling (BGG) or physical components.

Researched 2026-10-08 against every post in the BGG Rules, General, Strategy and Variants forums of Food Chain Magnate and the Ketchup expansion (designer posts by Jeroen Doumen "JD" / jmdsplotter and Joris Wiersinga). Links point to the BGG article. Strength is given in each entry: designer ruling, rulebook text, or still unclear. Rulings that changed the engine are versioned (rules v3, `core/rulesVersion.ts`).
